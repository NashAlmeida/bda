BIG DATA ANALYTICS PRACTICAL
EXPERIMENT 3

AIM:
To create Hive database and perform statistical functions.

THEORY:
Apache Hive is a data warehouse infrastructure built on top of Hadoop. It is used to store, manage, and analyze large datasets. Hive provides an SQL-like language called HiveQL (Hive Query Language), allowing users to query data without writing complex MapReduce programs.

In this experiment, a Hive database is created to store student-related information such as student ID, name, age, and marks. A table is created inside the database and sample records are inserted. The data is retrieved and analyzed using HiveQL queries.

Descriptive analytics summarizes and helps understand existing data. Hive provides built-in statistical functions:
- COUNT() – counts the number of records.
- SUM() – calculates the total.
- AVG() – calculates the average.
- MIN() – finds the minimum value.
- MAX() – finds the maximum value.
- STDDEV() – calculates standard deviation.
- VARIANCE() – calculates variance.
- GROUP BY – groups records for category-wise analysis.
- ORDER BY – sorts query results.

ENVIRONMENT:
- Cloudera QuickStart VM
- Apache Hive
- Database: analytics_db
- Table: student_marks

IMPORTANT:
Run Hive commands after entering the Hive shell. The prompt should be:
hive>

To start Hive, use the Linux terminal:
hive

------------------------------------------------------------
4. DESCRIPTIVE STATISTICAL ANALYSIS
------------------------------------------------------------

1) COUNT – Total number of students

SELECT COUNT(*) FROM student_marks;

Expected result:
5

2) SUM – Total marks

SELECT SUM(marks) FROM student_marks;

Expected result:
384

3) AVG – Average marks

SELECT AVG(marks) FROM student_marks;

Expected result:
76.8

4) MIN – Minimum marks

SELECT MIN(marks) FROM student_marks;

Expected result:
61

5) MAX – Maximum marks

SELECT MAX(marks) FROM student_marks;

Expected result:
92

6) STDDEV – Standard deviation

SELECT STDDEV(marks) FROM student_marks;

Expected:
Returns the standard deviation of the marks.

7) VARIANCE – Variance

SELECT VARIANCE(marks) FROM student_marks;

Expected:
Returns the variance of the marks.

8) GROUP BY – Average marks according to age

SELECT age, AVG(marks)
FROM student_marks
GROUP BY age;

Expected result:
age 20 -> average marks 74
age 21 -> average marks 88

9) ORDER BY – Sort students by marks in descending order

SELECT * FROM student_marks
ORDER BY marks DESC;

Expected order:
Karan  - 92
Rahul  - 88
Amit   - 75
Neha   - 68
Priya  - 61

6. VIVA QUESTIONS AND ANSWERS
------------------------------------------------------------

Q1. What is Apache Hive?
Ans: Hive is a data warehouse tool built on Hadoop. It is used to query and analyze large datasets.

Q2. What is HiveQL?
Ans: HiveQL is the SQL-like query language used to work with data in Hive.

Q3. What is a Hive database?
Ans: A database in Hive is a logical namespace used to organize tables.

Q4. What is a Hive table?
Ans: A table stores structured data in rows and columns and can be queried using HiveQL.

Q5. What is the use of CREATE DATABASE?
Ans: It creates a new database in Hive.

Q6. What is the use of USE?
Ans: It selects the database in which subsequent commands will run.

Q7. What is the use of SHOW TABLES?
Ans: It displays the tables in the currently selected database.

Q8. What does COUNT() do?
Ans: It counts the number of records.

Q9. What does SUM() do?
Ans: It calculates the total of numeric values.

Q10. What does AVG() do?
Ans: It calculates the arithmetic mean of numeric values.

Q11. What do MIN() and MAX() do?
Ans: MIN() returns the smallest value and MAX() returns the largest value.

Q12. What is STDDEV()?
Ans: It calculates the standard deviation, which describes how spread out values are around the mean.

Q13. What is VARIANCE()?
Ans: It measures the spread of values around the mean using squared deviations.

Q14. What is GROUP BY?
Ans: It groups rows with the same value so aggregate functions can be calculated for each group.

Q15. What is ORDER BY?
Ans: It sorts the query result in ascending or descending order.

Q16. What is the difference between GROUP BY and ORDER BY?
Ans: GROUP BY groups records for aggregate calculations; ORDER BY sorts the result.

Q17. What is the purpose of the student_marks table?
Ans: It stores student ID, name, age, and marks for analysis.

Q18. What is descriptive analytics?
Ans: It summarizes existing data to understand its characteristics and patterns.
